# Cloud-Based Payroll Management System

A responsive frontend-based Cloud Payroll Management System developed using HTML, CSS, Bootstrap, and JavaScript. The project demonstrates payroll management for different user roles with modern dashboards and responsive UI.

---

## 🚀 How to Run

1. Clone the project.
2. Open the project folder in **Visual Studio Code**.
4. Run **index.html**
5. Login to access the different roles and navigate through different modules.
